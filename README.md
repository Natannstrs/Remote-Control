# Remote-Control
remote control for laptop/PC controlled via mobile phone by connecting via IP Address port connected via the same network center (2 devices connected to the same WiFi)

🖥️💻Remote Laptop Control via Android (No App)
--This project allows you to control your laptop from your Android device using a local Wi-Fi network via a website.

⚙️How to use:
- Run "server.py" on your laptop.
- Enter the IP address and port on your Android device that will appear after running the "server.py" program.
- Enter the assigned token.
- Congratulations! You can now control your laptop.
